# Yandex Pro Profi

Мобильное веб-приложение для водителей Яндекс Такси: подсказки, куда ехать за выгодными заказами (аэропорты, вокзалы, события).

## Тестовый доступ

- **Логин:** `profi`
- **Пароль:** `YandexPro2026!`

Регистрация отключена.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Стек

- Next.js (App Router)
- TypeScript + Tailwind CSS
- Cookie-сессии (JWT / jose)

## Данные

Источник: [Яндекс Расписания](https://rasp.yandex.ru/).

- **Аэропорты** — реальные прилёты (с учётом задержек, если есть в табло). Обновление по кнопке «Обновить». Пассажиры — оценка по числу рейсов × средняя загрузка.
- **Вокзалы** — реальное расписание поездов дальнего следования (кэш на сутки). Электрички точнее с ключом `YANDEX_RASP_API_KEY`.
- **События** — афиша выбранного города на 3 дня (сегодня / завтра / послезавтра) из [KudaGo](https://kudago.com/). Сейчас город: **Москва**.

Ключ API (опционально): [Кабинет разработчика Яндекса](https://developer.tech.yandex.ru/) → API Яндекс Расписаний.

Сейчас город: **Москва**.
