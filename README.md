# Yandex Pro Profi

Мобильное веб-приложение для водителей Яндекс Такси: подсказки, куда ехать за выгодными заказами (аэропорты, вокзалы, события).

## Тестовый доступ

- **Логин:** `profi`
- **Пароль:** `YandexPro2026!`

Регистрация отключена.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Стек

- Next.js (App Router)
- TypeScript + Tailwind CSS
- Cookie-сессии (JWT / jose)

## Данные

- **Вокзалы** — расписание на сутки (стабильное в течение дня).
- **Аэропорты** — обновление при нажатии «Обновить» (прилёты могут сдвигаться).
