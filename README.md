# Yandex Pro Profi

Мобильное веб-приложение для водителей Яндекс Такси: подсказки, куда ехать за выгодными заказами (аэропорты, вокзалы, события).

## Тестовый доступ

- **Логин:** `profi`
- **Пароль:** `YandexPro2026!`

Регистрация отключена.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Стек

- Next.js (App Router)
- TypeScript + Tailwind CSS
- Cookie-сессии (JWT / jose)

## Данные

- **Вокзалы** — расписание на сутки (стабильное в течение дня). Час в карточке = время прибытия поезда; пассажиры выходят через 10–15 мин и около получаса (напр. 16:00 → выход 16:10–16:45, подъехать к 16:10).
- **Аэропорты** — обновление при нажатии «Обновить». Час = время посадки; выход через ~30–75 мин (напр. 16:00 → выход 16:30–17:15, подъехать к 16:30).
